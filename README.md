MY PREPROCESSOR PROJECT

Project Overview

MY PREPROCESSOR is a C programming project that demonstrates the basic operations performed by a C preprocessor before compilation.

Functionalities

1. Comment Removal: Removes comments from C source code.
2. File Inclusion: Handles header file inclusion.
3. Macro Substitution: Replaces object-like macros.
4. Function-like Macro Substitution:Processes function-like macros.
5. The project provides a menu-driven main program that allows users to select and execute each preprocessing module.
   on-like Macro Substitution: Processes function-like macros.

Technologies Used

- C Programming
- GCC Compiler
- Ubuntu Linux
- Git and GitHub

Project Files

The repository contains C source files, header files, input files, and generated ".i" output files for testing the individual functionalities.

Compilation

Example command to compile a generated preprocessed file:

gcc -x c output.i -o final
./final

Project Objective

To understand how basic preprocessing operations work in C and how source code is transformed before compilation.
